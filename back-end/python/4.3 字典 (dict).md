# 4.3 容器类型 - 字典 (dict)

> 面向前端开发者：Python 字典详解，对比 JavaScript Object/Map 理解

## 1. 创建字典

```python
# 字面量语法 - 键必须是字符串（用引号）
person = {'name': 'Alice', 'age': 25}

# 空字典
empty = {}
empty2 = dict()

# 从键值对列表创建
d = dict([('name', 'Alice'), ('age', 25)])

# 关键字参数（键必须是合法标识符）
d = dict(name='Alice', age=25)
```

**对比 JavaScript**：

```javascript
// JS 对象
const person = { name: 'Alice', age: 25 };

// JS Map
const map = new Map([['name', 'Alice'], ['age', 25]]);
```

## 2. 访问字典

### 基本访问

```python
person = {'name': 'Alice', 'age': 25}

# 方括号访问
person['name']  # 'Alice'
person['age']   # 25

# ❌ 点语法不行！（与 JS 不同）
person.name  # AttributeError!
```

### 安全访问（get 方法）

```python
person = {'name': 'Alice', 'age': 25}

# get() - 键不存在时返回 None，不报错
person.get('name')        # 'Alice'
person.get('job')         # None
person.get('job', 'Unknown')  # 'Unknown' (默认值)

# 对比：方括号访问不存在的键会报错
person['job']  # KeyError: 'job'
```

**对比 JavaScript**：

```javascript
// JS 可选链
person?.name
person?.job ?? 'Unknown'

// JS 直接访问不存在的属性返回 undefined，不报错
person.job  // undefined
```

### 检查键是否存在

```python
person = {'name': 'Alice', 'age': 25}

# in 运算符
'name' in person     # True
'job' in person      # False
'job' not in person  # True

# get() 返回 None 也可以判断
person.get('job') is None  # True
```

**对比 JavaScript**：

```javascript
'name' in person      // true
person.hasOwnProperty('name')  // true
```

## 3. 修改字典

### 添加/修改值

```python
person = {'name': 'Alice', 'age': 25}

# 添加新键值对
person['city'] = 'Beijing'
# {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# 修改已有值
person['age'] = 26
# {'name': 'Alice', 'age': 26, 'city': 'Beijing'}
```

### 删除值

```python
person = {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# del 语句
del person['age']
# {'name': 'Alice', 'city': 'Beijing'}

# pop() - 删除并返回值
age = person.pop('city')
print(age)    # 'Beijing'
print(person) # {'name': 'Alice'}

# popitem() - 删除并返回最后一个键值对（Python 3.7+）
person = {'name': 'Alice', 'age': 25}
key, value = person.popitem()
print(key, value)  # 'age' 25

# clear() - 清空
person.clear()
print(person)  # {}
```

**对比 JavaScript**：

```javascript
delete person.age;       // del
const age = person.pop('age');  // 类似 pop
person.clear();          // clear (Map 的方法)
```

## 4. 常用方法

| 方法 | 说明 | 返回值 | JS 对应 |
|------|------|--------|--------|
| `get(key[, default])` | 获取值 | 值或 default | `obj?.key ?? default` |
| `setdefault(key, default)` | 获取或设置 | 值 | 无直接对应 |
| `pop(key)` | 删除并返回 | 值 | 无直接对应 |
| `popitem()` | 删除最后一个 | (key, value) | 无直接对应 |
| `keys()` | 所有键 | 视图对象 | `Object.keys()` |
| `values()` | 所有值 | 视图对象 | `Object.values()` |
| `items()` | 所有键值对 | 视图对象 | `Object.entries()` |
| `update(dict)` | 更新字典 | None | `Object.assign()` |
| `clear()` | 清空 | None | `clear()` (Map) |
| `copy()` | 浅拷贝 | 新字典 | `{...obj}` |

### setdefault 示例

```python
person = {'name': 'Alice'}

# 如果键不存在，设置默认值并返回
city = person.setdefault('city', 'Beijing')
print(city)   # 'Beijing'
print(person) # {'name': 'Alice', 'city': 'Beijing'}

# 如果键已存在，返回原值，不修改
name = person.setdefault('name', 'Bob')
print(name)   # 'Alice' (不变)
print(person) # {'name': 'Alice', 'city': 'Beijing'}
```

### update 示例

```python
person = {'name': 'Alice', 'age': 25}

# 用另一个字典更新
person.update({'city': 'Beijing', 'age': 26})
print(person)  # {'name': 'Alice', 'age': 26, 'city': 'Beijing'}

# 用关键字参数更新
person.update(job='Engineer', city='Shanghai')
print(person)  # {'name': 'Alice', 'age': 26, 'city': 'Shanghai', 'job': 'Engineer'}
```

**对比 JavaScript**：

```javascript
Object.assign(person, { city: 'Beijing', age: 26 });
```

## 5. 遍历字典

```python
person = {'name': 'Alice', 'age': 25, 'city': 'Beijing'}

# 遍历键
for key in person:
    print(key)  # name, age, city

# 遍历键（显式）
for key in person.keys():
    print(key)

# 遍历值
for value in person.values():
    print(value)  # Alice, 25, Beijing

# 遍历键值对
for key, value in person.items():
    print(f"{key}: {value}")
    # name: Alice
    # age: 25
    # city: Beijing
```

**对比 JavaScript**：

```javascript
// 遍历键
for (const key in person) {}

// 遍历值
for (const value of Object.values(person)) {}

// 遍历键值对
for (const [key, value] of Object.entries(person)) {}
```

## 6. 字典的键类型

```python
# ✅ 可以作为键的类型（不可变类型）
d = {
    'name': 'Alice',      # 字符串
    42: 'answer',         # 数字
    (1, 2): 'point',      # 元组
    True: 'yes',          # 布尔
    None: 'nothing',      # None
}

# ❌ 不能作为键的类型（可变类型）
d = {
    [1, 2]: 'list',       # TypeError: unhashable type: 'list'
    {'a': 1}: 'dict',     # TypeError: unhashable type: 'dict'
}
```

**对比 JavaScript**：

```javascript
// JS 对象的键会自动转为字符串
const obj = {
    [1, 2]: 'list',  // 键变成 "1,2"
};

// JS Map 可以用任何类型作为键
const map = new Map();
map.set([1, 2], 'list');  // ✅ 可以
map.set({a: 1}, 'dict');  // ✅ 可以
```

## 7. 字典推导式

```python
# 基本语法
squares = {x: x**2 for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 带条件
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}
# {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}

# 交换键值对
person = {'name': 'Alice', 'age': 25}
swapped = {v: k for k, v in person.items()}
# {'Alice': 'name', 25: 'age'}

# 从两个列表创建字典
keys = ['name', 'age', 'city']
values = ['Alice', 25, 'Beijing']
person = dict(zip(keys, values))
# {'name': 'Alice', 'age': 25, 'city': 'Beijing'}
```

**对比 JavaScript**：

```javascript
// JS 没有字典推导式，用 reduce 或 Object.fromEntries
const squares = Object.fromEntries(
    Array.from({length: 5}, (_, i) => [i, i**2])
);
```

## 8. 常见陷阱

### 陷阱 1：点语法访问

```python
person = {'name': 'Alice'}

# ❌ 错误
person.name  # AttributeError!

# ✅ 正确
person['name']  # 'Alice'
person.get('name')  # 'Alice'
```

### 陷阱 2：访问不存在的键

```python
person = {'name': 'Alice'}

# ❌ 会报错
person['age']  # KeyError!

# ✅ 安全访问
person.get('age')  # None
person.get('age', 0)  # 0 (默认值)
```

### 陷阱 3：可变类型作为键

```python
# ❌ 错误
d = {[1, 2]: 'value'}  # TypeError!

# ✅ 正确
d = {(1, 2): 'value'}  # 用元组
```

### 陷阱 4：遍历中修改

```python
d = {'a': 1, 'b': 2, 'c': 3}

# ❌ 可能出错
for key in d:
    if key == 'b':
        del d[key]  # RuntimeError!

# ✅ 正确 - 先收集要删除的键
keys_to_delete = [k for k in d if k == 'b']
for key in keys_to_delete:
    del d[key]
```

## 9. 字典 vs JavaScript 对象

| 特性 | Python dict | JavaScript Object |
|------|-------------|-------------------|
| 语法 | `{'key': value}` | `{key: value}` |
| 访问 | `d['key']` | `obj.key` 或 `obj['key']` |
| 键类型 | 不可变类型 | 自动转字符串 |
| 遍历 | `items()`, `keys()`, `values()` | `Object.entries()` 等 |
| 长度 | `len(d)` | `Object.keys(d).length` |
| 删除 | `del d['key']` | `delete obj.key` |
| 安全访问 | `d.get('key')` | `obj?.key` |
