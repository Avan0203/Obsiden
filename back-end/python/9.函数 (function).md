# 9. 函数 (function)

> 面向前端开发者：Python 函数详解，对比 JavaScript function 理解

---

## 1. 定义函数

```python
# 基本语法
def greet(name):
    return f"Hello, {name}!"

# 调用
result = greet("Alice")
print(result)  # Hello, Alice!
```

**对比 JavaScript**：

```javascript
// 函数声明
function greet(name) {
    return `Hello, ${name}!`;
}

// 箭头函数
const greet = (name) => `Hello, ${name}!`;
```

## 2. 返回值

```python
# 有返回值
def add(a, b):
    return a + b

result = add(3, 5)  # 8

# 没有返回值（返回 None）
def say_hello():
    print("Hello!")

result = say_hello()
print(result)  # None

# 返回多个值（实际是返回元组）
def get_user():
    return "Alice", 25, "Engineer"

name, age, job = get_user()
print(name)  # Alice
print(age)   # 25
```

**对比 JavaScript**：

```javascript
// 没有 return 返回 undefined
function sayHello() {
    console.log("Hello!");
}
const result = sayHello();
console.log(result);  // undefined

// 返回多个值需要用数组或对象
function getUser() {
    return ["Alice", 25, "Engineer"];
}
const [name, age, job] = getUser();
```

## 3. 参数类型

### 位置参数

```python
def greet(name, greeting):
    return f"{greeting}, {name}!"

greet("Alice", "Hello")  # Hello, Alice!
```

### 默认参数

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

greet("Alice")           # Hello, Alice!
greet("Alice", "Hi")     # Hi, Alice!
```

**对比 JavaScript**：

```javascript
// JS 默认参数
function greet(name, greeting = "Hello") {
    return `${greeting}, ${name}!`;
}
```

### 关键字参数

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

# 使用关键字参数（可以打乱顺序）
greet(name="Alice", greeting="Hi")  # Hi, Alice!
greet(greeting="Hi", name="Alice")  # Hi, Alice! (顺序无关)
```

**对比 JavaScript**：

```javascript
// JS 没有直接的关键字参数，需要传对象
function greet({ name, greeting = "Hello" }) {
    return `${greeting}, ${name}!`;
}
greet({ name: "Alice", greeting: "Hi" });
```

## 4. 可变参数

### *args - 可变位置参数

```python
def sum_all(*args):
    total = 0
    for n in args:
        total += n
    return total

sum_all(1, 2, 3)      # 6
sum_all(1, 2, 3, 4, 5)  # 15

# args 是元组
def print_args(*args):
    print(type(args))  # <class 'tuple'>
    print(args)

print_args(1, 2, 3)  # (1, 2, 3)
```

**对比 JavaScript**：

```javascript
// JS rest 参数
function sumAll(...args) {
    return args.reduce((a, b) => a + b, 0);
}
```

### **kwargs - 可变关键字参数

```python
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25, city="Beijing")
# name: Alice
# age: 25
# city: Beijing

# kwargs 是字典
def print_kwargs(**kwargs):
    print(type(kwargs))  # <class 'dict'>
    print(kwargs)

print_kwargs(a=1, b=2)  # {'a': 1, 'b': 2}
```

**对比 JavaScript**：

```javascript
// JS 对象参数
function printInfo(obj) {
    for (const [key, value] of Object.entries(obj)) {
        console.log(`${key}: ${value}`);
    }
}
printInfo({ name: "Alice", age: 25 });
```

### 混合使用

```python
def func(a, b, *args, default=True, **kwargs):
    print(f"a: {a}, b: {b}")
    print(f"args: {args}")
    print(f"default: {default}")
    print(f"kwargs: {kwargs}")

func(1, 2, 3, 4, 5, default=False, name="Alice", age=25)
# a: 1, b: 2
# args: (3, 4, 5)
# default: False
# kwargs: {'name': 'Alice', 'age': 25}
```

**参数顺序规则**：

```python
def func(位置参数，默认参数，*args, 命名关键字参数，**kwargs):
    pass
```

## 5. 解包参数

```python
# 列表/元组解包
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
add(*nums)  # 6 (相当于 add(1, 2, 3))

# 字典解包
def greet(name, greeting):
    return f"{greeting}, {name}!"

params = {"name": "Alice", "greeting": "Hi"}
greet(**params)  # Hi, Alice! (相当于 greet(name="Alice", greeting="Hi"))
```

**对比 JavaScript**：

```javascript
// JS 展开运算符
function add(a, b, c) {
    return a + b + c;
}
const nums = [1, 2, 3];
add(...nums);  // 6

const params = { name: "Alice", greeting: "Hi" };
greet(params);  // 需要修改函数接收对象
```

## 6. Lambda 函数（匿名函数）

```python
# 基本语法
add = lambda a, b: a + b
print(add(3, 5))  # 8

# 常用于高阶函数
nums = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, nums))
print(squared)  # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)  # [2, 4]
```

**对比 JavaScript**：

```javascript
// JS 箭头函数
const add = (a, b) => a + b;

const squared = nums.map(x => x ** 2);
const evens = nums.filter(x => x % 2 === 0);
```

## 7. 作用域

```python
# 全局变量
x = 10

def func():
    # 局部变量
    y = 5
    print(x)  # 可以访问全局变量
    print(y)  # 可以访问局部变量

func()
print(x)  # 10
# print(y)  # NameError! y 是局部变量

# 修改全局变量
def modify_global():
    global x
    x = 20

modify_global()
print(x)  # 20
```

**对比 JavaScript**：

```javascript
let x = 10;

function func() {
    let y = 5;
    console.log(x);  // 可以访问
    console.log(y);  // 可以访问
}
console.log(x);  // 10
// console.log(y);  // ReferenceError!

// 修改全局变量
function modifyGlobal() {
    x = 20;  // 不需要 global 关键字
}
```

## 8. 常见陷阱

### 陷阱 1：可变默认参数

```python
# ❌ 错误 - 默认参数是可变类型
def append(x, lst=[]):
    lst.append(x)
    return lst

print(append(1))  # [1]
print(append(2))  # [1, 2] ← 不是 [2]！默认参数被重用了！

# ✅ 正确 - 用 None 作为默认值
def append(x, lst=None):
    if lst is None:
        lst = []
    lst.append(x)
    return lst

print(append(1))  # [1]
print(append(2))  # [2] ← 正确！
```

### 陷阱 2：闭包中的变量

```python
# ❌ 错误 - 闭包捕获的是变量引用
funcs = []
for i in range(3):
    funcs.append(lambda: i)

print([f() for f in funcs])  # [2, 2, 2] ← 都是 2！

# ✅ 正确 - 用默认参数捕获当前值
funcs = []
for i in range(3):
    funcs.append(lambda x=i: x)

print([f() for f in funcs])  # [0, 1, 2] ← 正确！
```

## 9. 函数注解（类型提示）

```python
# Python 3.5+ 类型提示
def greet(name: str, greeting: str = "Hello") -> str:
    return f"{greeting}, {name}!"

# 注解存储在__annotations__中
print(greet.__annotations__)
# {'name': <class 'str'>, 'greeting': <class 'str'>, 'return': <class 'str'>}

# 类型提示不影响运行，只是给 IDE 和工具看的
```

**对比 TypeScript**：

```typescript
function greet(name: string, greeting: string = "Hello"): string {
    return `${greeting}, ${name}!`;
}
```
