## 1. 数值类型 (int, float)

### 整数 (int)

```python
# 整数定义
x = 10
y = -5
z = 0

# 大整数（Python 特色！）
big = 2 ** 1000  # 可以正常计算，不会溢出！
print(big)  # 显示完整数字
```

**对比 JavaScript**：
```javascript
// JS 有安全整数限制
Number.MAX_SAFE_INTEGER  // 2^53 - 1 = 9007199254740991
// 超出后丢失精度
9007199254740992 === 9007199254740993  // true! (精度丢失)

// Python 没有这个问题
2**1000 == 2**1000 + 1  # False (精确)
```

### 浮点数 (float)

```python
# 浮点数定义
pi = 3.14159
negative = -0.5
scientific = 1.5e-10  # 科学计数法：1.5 × 10^-10
```

**对比 JavaScript**：
```javascript
// JS 只有 number 类型（双精度浮点）
const pi = 3.14159;
const scientific = 1.5e-10;

// Python 区分 int 和 float
```

### 除法运算

| 运算符 | 说明 | 示例 | 结果类型 |
|--------|------|------|----------|
| `/` | 浮点除法 | `10 / 3` | `float` (3.333...) |
| `//` | 整除 | `10 // 3` | `int` (3) |
| `%` | 取余 | `10 % 3` | `int` (1) |
| `**` | 幂运算 | `2 ** 3` | `int` (8) |

```python
# 除法示例
10 / 3    # 3.3333333333333335 (float)
10 // 3   # 3 (int)
10 % 3    # 1 (int)
2 ** 3    # 8 (int)
2.0 ** 3  # 8.0 (float) - 有 float 参与运算
```

### 数值运算的类型规则

```python
# int + int = int
1 + 2      # 3 (int)

# int + float = float
1 + 2.5    # 3.5 (float)

# float + float = float
1.5 + 2.5  # 4.0 (float)

# 规则：只要有 float 参与，结果就是 float
```

## 2. 布尔类型 (bool)

### 基本定义

```python
is_active = True
is_deleted = False

# 注意：首字母大写！
true   # ❌ NameError
True   # ✅ 正确
```

**对比 JavaScript**：
```javascript
// JS 小写
const isActive = true;
const isDeleted = false;
```

### 真值判断（重要！）

以下值在布尔上下文中为 `False`：
```python
False       # 布尔假
None        # 空值
0           # 零
0.0         # 零浮点
""          # 空字符串
[]          # 空列表
{}          # 空字典
()          # 空元组
set()       # 空集合
```

其他所有值都为 `True`。

```python
# 示例
if 0:
    print("不会执行")

if 1:
    print("会执行")  # 1 被视为 True

if "":
    print("不会执行")

if "hello":
    print("会执行")  # 非空字符串被视为 True
```

**对比 JavaScript**：
```javascript
// JS 的假值
false, 0, "", null, undefined, NaN

// Python 没有 undefined 和 NaN，用 None 表示空值
```

## 3. 类型检查

### type() 函数

```python
x = 10
print(type(x))  # <class 'int'>

y = 3.14
print(type(y))  # <class 'float'>

z = True
print(type(z))  # <class 'bool'>
```

### isinstance() 函数（推荐）

```python
x = 10
isinstance(x, int)      # True
isinstance(x, float)    # False

# 检查多个类型
isinstance(x, (int, float))  # True (是 int 或 float 吗？)
```

**type() vs isinstance()**：
```python
class MyInt(int):
    pass

obj = MyInt(10)

type(obj) == int        # False (是 MyInt 类，不是 int 类)
isinstance(obj, int)    # True (MyInt 继承自 int)
```

## 4. Python vs JavaScript 类型对照

| 功能 | JavaScript | Python |
|------|------------|--------|
| 整数 | `number` | `int` |
| 浮点数 | `number` | `float` |
| 布尔值 | `boolean` (`true/false`) | `bool` (`True/False`) |
| 空值 | `null` / `undefined` | `None` |
| 类型检查 | `typeof x` | `type(x)` / `isinstance(x, type)` |
| 整数范围 | 安全整数 2^53-1 | 无限制（任意精度） |
| 除法 | `/` 总是浮点 | `/` 浮点，`//` 整除 |

## 5. 常见陷阱

### 陷阱 1：浮点数精度

```python
# Python 和 JS 都有这个问题
0.1 + 0.2 == 0.3  # False!
print(0.1 + 0.2)  # 0.30000000000000004
```

**解决方案**：使用 `round()` 或 `decimal` 模块

```python
round(0.1 + 0.2, 1) == 0.3  # True

# 或精确计算
from decimal import Decimal
Decimal('0.1') + Decimal('0.2') == Decimal('0.3')  # True
```

### 陷阱 2：整数除法

```python
# Python 3 中 / 总是返回 float
10 / 5   # 2.0 (不是 2！)
10 // 5  # 2 (整除)
```

### 陷阱 3：大小写敏感

```python
True   # ✅
true   # ❌ NameError

False  # ✅
false  # ❌ NameError

None   # ✅
none   # ❌ NameError
```
