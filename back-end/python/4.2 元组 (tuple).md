## 1. 创建元组

```python
# 基本语法 - 使用圆括号
t = (1, 2, 3)
print(t)  # (1, 2, 3)

# 空元组
empty = ()
empty2 = tuple()

# 从其他可迭代对象转换
t1 = tuple([1, 2, 3])     # 从列表
t2 = tuple("abc")         # 从字符串 → ('a', 'b', 'c')
t3 = tuple({1, 2, 3})     # 从集合
```

### ⚠️ 单元素元组（重要！）

```python
# ✅ 正确 - 必须有逗号！
t = (42,)
print(type(t))  # <class 'tuple'>

# ❌ 错误 - (42) 只是括号表达式，不是元组
t = (42)
print(type(t))  # <class 'int'>

# 逗号才是元组的标志，括号只是可选的
t = 42,
print(type(t))  # <class 'tuple'>
print(t)        # (42,)
```

**对比 JavaScript**：

```javascript
// JS 没有元组，只有数组
const t = [1, 2, 3];
// 如果用 Object.freeze 可以实现类似不可变性
const frozen = Object.freeze([1, 2, 3]);
```

## 2. 元组的不可变性

```python
t = (1, 2, 3)

# ✅ 可以做的
t[0]        # 1 (访问)
t[1:3]      # (2, 3) (切片)
t + (4, 5)  # (1, 2, 3, 4, 5) (创建新元组)
t * 2       # (1, 2, 3, 1, 2, 3) (创建新元组)

# ❌ 不可以做的
t[0] = 10   # TypeError: 'tuple' object does not support item assignment
t.append(4) # AttributeError: 'tuple' object has no attribute 'append'
t.pop()     # AttributeError: 'tuple' object has no attribute 'pop'
```

### 为什么需要元组？

1. **数据安全性**：确保数据不会被意外修改
2. **可用作字典的键**（列表不行！）
3. **性能更好**：不可变类型，内存占用更小
4. **语义清晰**：表示"这是一组固定的值"

```python
# 示例：坐标点（不应该被修改）
point = (10, 20)

# 示例：字典的键
locations = {
    (0, 0): "原点",
    (1, 0): "X 轴",
    (0, 1): "Y 轴",
}
# locations[[0, 0]] = "原点"  # ❌ TypeError: list 不能作为键！
```

## 3. 元组操作

### 拼接和重复

```python
t1 = (1, 2, 3)
t2 = (4, 5, 6)

# 拼接
t1 + t2      # (1, 2, 3, 4, 5, 6)

# 重复
t1 * 2       # (1, 2, 3, 1, 2, 3)
t1 * 3       # (1, 2, 3, 1, 2, 3, 1, 2, 3)
```

### 索引和切片

```python
t = (10, 20, 30, 40, 50)

# 索引
t[0]      # 10
t[-1]     # 50 (最后一个)
t[-2]     # 40 (倒数第二个)

# 切片（返回新元组）
t[1:4]    # (20, 30, 40)
t[:3]     # (10, 20, 30)
t[2:]     # (30, 40, 50)
t[::-1]   # (50, 40, 30, 20, 10) - 反转
t[::2]    # (10, 30, 50) - 隔一个取一个
```

**对比 JavaScript**：

```javascript
const t = [10, 20, 30, 40, 50];
t[0]           // 10
t[t.length-1]  // 50
t.slice(1, 4)  // [20, 30, 40]
t.slice().reverse()  // [50, 40, 30, 20, 10]
```

## 4. 元组解包（Unpacking）

```python
# 基本解包
t = (1, 2, 3)
a, b, c = t
print(a)  # 1
print(b)  # 2
print(c)  # 3

# 等价于
a, b, c = 1, 2, 3

# 交换变量
x, y = 1, 2
x, y = y, x  # x=2, y=1
```

### 部分解包（* 语法）

```python
# * 收集剩余元素
first, *rest = (1, 2, 3, 4, 5)
print(first)  # 1
print(rest)   # [2, 3, 4, 5]

# 收集中间
first, *middle, last = (1, 2, 3, 4, 5)
print(first)   # 1
print(middle)  # [2, 3, 4]
print(last)    # 5

# 丢弃不需要的值（用 _）
x, _, z = (1, 2, 3)
print(x)  # 1
print(z)  # 3
# _ 是 2，但按约定表示"忽略这个值"
```

**对比 JavaScript**：

```javascript
// JS 解构赋值
const [a, b, c] = [1, 2, 3];
const [first, ...rest] = [1, 2, 3, 4, 5];
const [x, , z] = [1, 2, 3];  // 忽略中间值
```

## 5. 元组方法

元组的方法很少（因为不可变）：

```python
t = (1, 2, 2, 3, 2, 4)

# count - 统计元素出现次数
t.count(2)  # 3

# index - 查找元素索引
t.index(3)  # 3
t.index(2)  # 1 (返回第一个匹配的索引)
```

## 6. 元组 vs 列表

| 特性 | 元组 (tuple) | 列表 (list) |
|------|--------------|-------------|
| 语法 | `(1, 2, 3)` | `[1, 2, 3]` |
| 可变性 | ❌ 不可变 | ✅ 可变 |
| 方法 | `count()`, `index()` | 很多 (`append`, `pop`, `sort` 等) |
| 性能 | 更快，内存更小 | 稍慢 |
| 可作字典键 | ✅ 可以 | ❌ 不可以 |
| 使用场景 | 固定数据、记录 | 动态数据、集合 |

### 何时使用元组？

```python
# ✅ 适合用元组的场景

# 1. 固定的数据集合
RGB_RED = (255, 0, 0)
COORDINATES = (10, 20)

# 2. 函数的多个返回值
def get_user():
    return ("Alice", 25, "Engineer")  # 返回元组

name, age, job = get_user()

# 3. 字典的键
locations = {
    (0, 0): "原点",
    (1, 1): "对角",
}

# 4. 数据库记录
user_record = (1, "Alice", "alice@example.com")
```

## 7. 常见陷阱

### 陷阱 1：单元素元组

```python
# ❌ 错误
t = (42)
print(type(t))  # <class 'int'>

# ✅ 正确
t = (42,)
print(type(t))  # <class 'tuple'>
```

### 陷阱 2：元组内的可变元素

```python
# 元组本身不可变，但可以包含可变对象
t = ([1, 2], [3, 4])
t[0].append(3)  # ✅ 可以！修改的是列表，不是元组
print(t)        # ([1, 2, 3], [3, 4])

t[0] = [5, 6]   # ❌ TypeError! 不能修改元组的元素引用
```

### 陷阱 3：空元组

```python
# ✅ 正确
empty = ()
empty2 = tuple()

# ❌ 错误 - 这是空列表
empty = []
```

## 8. 命名元组（进阶）

```python
from collections import namedtuple

# 创建命名元组类
Point = namedtuple('Point', ['x', 'y'])

# 使用
p = Point(10, 20)
print(p.x)  # 10 (可以属性访问)
print(p.y)  # 20
print(p[0]) # 10 (也可以索引访问)

# 对比普通元组
p2 = (10, 20)
print(p2[0])  # 10
# print(p2.x)  # AttributeError!
```

**对比 JavaScript**：

```javascript
// 类似 JS 的对象
const p = { x: 10, y: 20 };
console.log(p.x);  // 10
```
