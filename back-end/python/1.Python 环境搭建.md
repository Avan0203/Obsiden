## 1. Python 安装（Windows）

### 安装步骤

1. **访问官网**：https://www.python.org/downloads/
2. **下载最新版本**：推荐 Python 3.12.x（最新稳定版）
3. **运行安装程序**：
   - ⚠️ **重要**：勾选 "Add Python to PATH"（将 Python 添加到环境变量）
   - 点击 "Install Now"
4. **验证安装**：
   ```bash
   python --version    # 输出：Python 3.12.0
   ```

### 验证安装成功

```bash
# 命令行输入
python --version

# 输出示例
Python 3.12.0
```

## 2. Python 解释器（REPL）

### 什么是 REPL？

REPL = Read-Eval-Print-Loop（读取 - 求值 - 输出 - 循环）

**对比前端**：类似 Node.js 的交互式命令行

### 使用方式

```bash
# 1. 打开命令行，输入 python 进入交互模式
$ python

# 2. 看到提示符 >>> 表示可以输入 Python 代码
Python 3.12.0 (main, ...)
>>> 1 + 1
2
>>> print("Hello, World!")
Hello, World!
>>> "Python".upper()
'PYTHON'

# 3. 退出交互模式
>>> exit()
# 或按 Ctrl+Z (Windows) / Ctrl+D (Mac/Linux)
```

## 3. 运行 Python 脚本

### 创建并运行第一个脚本

```python
# hello.py
print("Hello, World!")

name = "Frontend Developer"
print(f"Welcome to Python, {name}!")
```

```bash
# 运行脚本
python hello.py

# 输出
Hello, World!
Welcome to Python, Frontend Developer!
```

**对比 Node.js**：
```bash
node hello.js    # JavaScript
python hello.py  # Python
```

## 4. 常用运行方式

| 方式 | 命令 | 场景 | 前端类比 |
|------|------|------|----------|
| 交互模式 | `python` | 快速测试、学习语法 | `node` (无参数) |
| 运行脚本 | `python script.py` | 执行完整程序 | `node script.js` |
| 模块运行 | `python -m module_name` | 运行内置模块 | `npx xxx` |
| 检查语法 | `python -m py_compile script.py` | 检查语法错误 | `eslint xxx.js` |
| 格式化代码 | `python -m json.tool file.json` | 格式化 JSON | `prettier file.json` |

### 常用模块运行示例

```bash
# 启动简易 HTTP 服务器（类似 http-server）
python -m http.server 8000

# 查看 Python 搜索路径
python -c "import sys; print(sys.path)"

# 直接执行代码
python -c "print('Hello from command line!')"
```

## 6. 前端开发者快速上手

### Node.js vs Python 命令对照

| Node.js | Python | 说明 |
|---------|--------|------|
| `node -v` | `python --version` | 查看版本 |
| `node` | `python` | 进入 REPL |
| `node app.js` | `python app.py` | 运行脚本 |
| `npm install xxx` | `pip install xxx` | 安装包 |
| `package.json` | `requirements.txt` | 依赖管理 |
| `node_modules` | `venv/` | 本地依赖 |

## 7. 常见问题

### Q1: 输入 `python` 提示 "不是内部或外部命令"

**解决**：安装时未勾选 "Add Python to PATH"，重新安装并勾选即可。

### Q2: Windows 上有 `python` 和 `python3` 两个命令？

Windows 通常只有 `python` 命令，Linux/Mac 可能有 `python3`。

### Q3: 如何查看 Python 安装路径？

```bash
# Windows
where python

# Linux/Mac
which python3
```
