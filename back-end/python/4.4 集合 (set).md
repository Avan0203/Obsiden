# 4.4 容器类型 - 集合 (set)

> 面向前端开发者：Python 集合详解，对比 JavaScript Set 理解

## 1. 创建集合

```python
# 字面量语法
s = {1, 2, 3}
print(s)  # {1, 2, 3}

# 从列表创建（去重！）
nums = [1, 2, 2, 3, 3, 3]
s = set(nums)
print(s)  # {1, 2, 3}

# 空集合（注意！）
s = set()     # ✅ 正确
s = {}        # ❌ 这是空字典！

# 从字符串创建
s = set("hello")
print(s)  # {'h', 'e', 'l', 'o'} (去重，无序)
```

**对比 JavaScript**：

```javascript
// JS Set
const s = new Set([1, 2, 2, 3, 3, 3]);
console.log(s);  // Set(3) {1, 2, 3}

// 空 Set
const empty = new Set();
```

## 2. 集合特性

### 无序性

```python
s = {3, 1, 2}
print(s)  # 可能是 {1, 2, 3} 或其他顺序

# 不能通过索引访问
# s[0]  # TypeError!
```

### 不重复

```python
s = {1, 2, 2, 3, 3, 3}
print(s)  # {1, 2, 3} (自动去重)

# 添加已存在的元素，不会重复
s.add(2)
print(s)  # {1, 2, 3} (不变)
```

### 元素必须是不可变类型

```python
# ✅ 可以
s = {1, 2, "hello", (1, 2)}

# ❌ 不可以
s = {[1, 2], {"a": 1}}  # TypeError: unhashable type
```

## 3. 基本操作

### 添加元素

```python
s = {1, 2, 3}

# add - 添加单个元素
s.add(4)
print(s)  # {1, 2, 3, 4}

# update - 添加多个元素
s.update([5, 6, 7])
print(s)  # {1, 2, 3, 4, 5, 6, 7}

# update 可以传入任何可迭代对象
s.update({8, 9})
s.update(range(10, 13))
```

### 删除元素

```python
s = {1, 2, 3, 4, 5}

# remove - 删除元素，不存在会报错
s.remove(3)
print(s)  # {1, 2, 4, 5}
# s.remove(10)  # KeyError!

# discard - 删除元素，不存在不报错
s.discard(4)
print(s)  # {1, 2, 5}
s.discard(10)  # 不会报错

# pop - 随机删除并返回一个元素
elem = s.pop()
print(elem)  # 随机一个元素
print(s)     # 剩下的元素

# clear - 清空
s.clear()
print(s)  # set()
```

**对比 JavaScript**：

```javascript
s.add(4);
s.delete(3);      // remove
s.has(3);         // 检查存在
s.clear();
```

## 4. 集合运算

```python
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}

# 并集 | - 两个集合的所有元素
a | b  # {1, 2, 3, 4, 5, 6, 7, 8}
a.union(b)

# 交集 & - 两个集合共有的元素
a & b  # {4, 5}
a.intersection(b)

# 差集 - - 在 a 中但不在 b 中的元素
a - b  # {1, 2, 3}
a.difference(b)

# 对称差集 ^ - 只在一个集合中的元素
a ^ b  # {1, 2, 3, 6, 7, 8}
a.symmetric_difference(b)
```

**对比 JavaScript**：

```javascript
// JS Set 没有内置运算符，需要手动实现
const union = new Set([...a, ...b]);
const intersection = new Set([...a].filter(x => b.has(x)));
const difference = new Set([...a].filter(x => !b.has(x)));
```

## 5. 集合关系判断

```python
a = {1, 2, 3, 4, 5}
b = {2, 3, 4}
c = {1, 2, 3, 4, 5}

# 子集 <= - a 的所有元素都在 b 中
b <= a  # True (b 是 a 的子集)
b.issubset(a)

# 真子集 < - a 是 b 的子集且 a != b
b < a  # True

# 超集 >= - a 包含 b 的所有元素
a >= b  # True (a 是 b 的超集)
a.issuperset(b)

# 真超集 > - a 是 b 的超集且 a != b
a > b  # True

# 不相交 - 两个集合没有共同元素
{1, 2}.isdisjoint({3, 4})  # True
{1, 2}.isdisjoint({2, 3})  # False
```

## 6. 常用方法

| 方法 | 说明 | 返回值 | JS 对应 |
|------|------|--------|--------|
| `add(x)` | 添加元素 | None | `set.add(x)` |
| `remove(x)` | 删除元素 | None | `set.delete(x)` |
| `discard(x)` | 删除（不报错） | None | 无 |
| `pop()` | 随机删除 | 元素 | `无` |
| `clear()` | 清空 | None | `set.clear()` |
| `union(s)` | 并集 | 新集合 | `[...a, ...b]` |
| `intersection(s)` | 交集 | 新集合 | `filter` |
| `difference(s)` | 差集 | 新集合 | `filter` |
| `issubset(s)` | 是否子集 | bool | 无 |
| `issuperset(s)` | 是否超集 | bool | 无 |
| `isdisjoint(s)` | 是否不相交 | bool | 无 |

## 7. 集合推导式

```python
# 基本语法
squares = {x**2 for x in range(5)}
# {0, 1, 4, 9, 16}

# 带条件
evens = {x for x in range(10) if x % 2 == 0}
# {0, 2, 4, 6, 8}

# 从字符串去重
chars = {c for c in "hello world" if c != " "}
# {'h', 'e', 'l', 'o', 'w', 'r', 'd'}
```

## 8. 常见应用

### 应用 1：列表去重

```python
nums = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
unique = list(set(nums))
print(unique)  # [1, 2, 3, 4]
```

### 应用 2：快速查找

```python
# 集合查找是 O(1)，列表是 O(n)
valid_ids = {1, 2, 3, 4, 5}

# 快速判断
if user_id in valid_ids:  # O(1)
    print("Valid")

# 比列表快得多
valid_list = [1, 2, 3, 4, 5]
if user_id in valid_list:  # O(n)
    print("Valid")
```

### 应用 3：共同好友

```python
friends_a = {"Alice", "Bob", "Charlie", "David"}
friends_b = {"Bob", "Charlie", "Eve"}

# 共同好友
common = friends_a & friends_b
print(common)  # {"Bob", "Charlie"}
```

## 9. 冻结集合 (frozenset)

```python
# frozenset 是不可变的集合
fs = frozenset([1, 2, 3])

# ❌ 不能修改
fs.add(4)     # AttributeError!
fs.remove(1)  # AttributeError!

# ✅ 可以作为字典的键
d = {fs: "value"}  # ✅ 可以

# 普通集合不能做键
s = {1, 2, 3}
d = {s: "value"}  # TypeError!
```

## 10. 集合 vs 列表 vs 字典

| 特性 | set | list | dict |
|------|-----|------|------|
| 语法 | `{1, 2}` | `[1, 2]` | `{'k': 'v'}` |
| 有序 | ❌ | ✅ | ✅ (3.7+) |
| 可变 | ✅ | ✅ | ✅ |
| 重复 | ❌ | ✅ | ❌ (键) |
| 查找速度 | O(1) | O(n) | O(1) |
| 用途 | 去重、集合运算 | 有序集合 | 键值对映射 |
