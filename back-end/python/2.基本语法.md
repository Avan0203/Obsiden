## 1. 缩进规则（最重要！）

### Python 用**缩进**表示代码块，不用 `{}`

```python
# Python
def greet(name):
    if name:
        print(f"Hello, {name}!")  # 必须缩进
    else:
        print("Hello, Stranger!")  # 必须缩进
```

```javascript
// JavaScript
function greet(name) {
    if (name) {
        console.log(`Hello, ${name}!`);  // 缩进可选
    } else {
        console.log("Hello, Stranger!");
    }
}
```

### 缩进规范

| 规则 | 说明 |
|------|------|
| **使用空格，不用 Tab** | PEP 8 推荐 |
| **4 个空格 = 1 级缩进** | 标准约定 |
| **同一代码块缩进一致** | 不能混用 |

```python
# ✅ 正确
if True:
    print("A")
    print("B")

# ❌ 错误 - 缩进不一致
if True:
    print("A")
        print("B")  # IndentationError!

# ❌ 错误 - 混用 Tab 和空格
if True:
    print("A")   # Tab 缩进
    print("B")   # 空格缩进 → TabError!
```

### 常见错误

```python
# 错误：if 语句后缺少冒号
if True  # ❌ SyntaxError
    print("A")

# 正确
if True:  # ✅ 必须有冒号
    print("A")
```

## 2. 注释

### 单行注释

```python
# 这是单行注释（类似 JS //）
name = "Alice"  # 行尾注释
```

### 多行注释/文档字符串

```python
"""
这是多行注释
可以跨越多行
用于说明代码功能
"""

def greet(name):
    """
    这是函数的文档字符串
    说明函数的功能、参数、返回值
    """
    return f"Hello, {name}"
```

**对比 JavaScript**：
```javascript
// 单行注释
/* 多行注释 */

/**
 * JSDoc 文档注释
 * @param {string} name
 */
```

## 3. 变量定义

### Python 变量无需声明关键字

```python
# Python - 直接赋值
name = "Alice"
age = 25
is_active = True

# JavaScript - 需要 let/const/var
let name = "Alice";
const age = 25;
```

### 动态类型

```python
x = 10      # x 是整数
x = "hello" # 现在 x 是字符串（可以改变类型！）

# JavaScript 同理
let x = 10;
x = "hello";
```

### 变量命名规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 只能含字母、数字、下划线 | 不能以数字开头 | `name_1` ✅, `1name` ❌ |
| 区分大小写 | `Name` 和 `name` 不同 | |
| 不能用 Python 关键字 | `if`, `for`, `def` 等 | |
| 推荐用小写 + 下划线 | 蛇形命名法（snake_case） | `user_name` |

```python

#  'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 
#  'from', 'global', 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 
#  'not', 'or', 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']
```

## 4. 多重赋值

### 同时给多个变量赋值

```python
# 传统写法
x = 1
y = 2
z = 3

# Python 优雅写法
x, y, z = 1, 2, 3
```

### 交换变量值（无需临时变量）

```python
a, b = 1, 2
a, b = b, a  # a=2, b=1

# 对比 JS 需要临时变量或解构
// JS 传统写法
let temp = a;
a = b;
b = temp;

// JS 解构
[a, b] = [b, a];
```

### 链式赋值

```python
x = y = z = 0  # 三个变量都指向 0
```

### 解包赋值

```python
# 列表解包
coords = [1, 2, 3]
x, y, z = coords
print(x)  # 1

# 字符串解包
a, b, c = "ABC"
print(b)  # B

# 部分解包（* 收集剩余）
first, *rest = [1, 2, 3, 4]
print(first)  # 1
print(rest)   # [2, 3, 4]

# 对比 JavaScript
const [first, ...rest] = [1, 2, 3, 4];
```

## 5. 常量

Python 没有真正的常量，约定用**全大写**表示：

```python
PI = 3.14159
MAX_SIZE = 100

# 但实际上可以修改（靠自觉）
PI = 3.14  # 不会报错，但不推荐
```

**对比 JavaScript**：
```javascript
const PI = 3.14159;  // const 真正不可修改
Object.freeze({ PI });  // 冻结对象
```

## 6. Python vs JavaScript 语法对照表

| 功能 | JavaScript | Python |
|------|------------|--------|
| 变量声明 | `let x = 10` | `x = 10` |
| 常量声明 | `const PI = 3.14` | `PI = 3.14` (约定) |
| 代码块 | `{ ... }` | 缩进 |
| 语句结束符 | `;` (可选) | 不需要 |
| 单行注释 | `//` | `#` |
| 多行注释 | `/* */` | `""" """` |
| 空值 | `null` | `None` |
| 布尔值 | `true/false` | `True/False` |
| 逻辑运算 | `&& || !` | `and or not` |
