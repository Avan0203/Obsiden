## 前端开发者转 Python 学习路线（课程大纲）

| 阶段 | 学习模块 | 主题内容 | 关键知识点 | 备注 / 对前端类比 |
|-----|----------|----------|------------|------------------|
| 基础阶段 | Python 环境搭建 | Python安装、解释器、REPL、运行脚本 | python命令、py文件执行 | 类似 Node.js 运行 JS |
| 基础阶段 | 基本语法 | 缩进规则、注释、变量定义 | 动态类型、变量命名 | 类似 JS 但无 `var/let/const` |
| 基础阶段 | 数据类型 | int、float、str、bool | 基本类型操作 | 对应 JS number/string/boolean |
| 基础阶段 | 容器类型 | list、tuple、dict、set | 数据存储结构 | 类似 Array / Object / Set |
| 基础阶段 | 类型转换 | int()、str()、float()、list() | 类型转换规则 | 类似 JS Number()/String() |
| 基础阶段 | 运算符 | 算术、比较、逻辑、成员运算符 | and / or / not | 类似 JS 运算符 |
| 基础阶段 | 控制流 | if / elif / else | 条件判断 | 类似 JS if |
| 基础阶段 | 循环结构 | for / while | range、break、continue | Python for 更像 `for..of` |
| 基础阶段 | 函数 | 函数定义、返回值 | def、return | 类似 JS function |
| 基础阶段 | 函数参数 | 默认参数、关键字参数、可变参数 | *args / **kwargs | 类似 JS rest |
| 基础阶段 | 常用内置函数 | len、type、range、enumerate、zip | 常用工具函数 | 类似 lodash 一部分功能 |
| 基础阶段 | 字符串处理 | 字符串格式化 | f-string、format | 类似模板字符串 |
| 基础阶段 | 列表操作 | 列表方法 | append、extend、pop | 类似 JS array methods |
| 基础阶段 | 推导式 | 列表推导、字典推导 | list comprehension | 类似 map/filter |
| 进阶阶段 | 文件操作 | 文件读写 | open、read、write | 类似 Node fs |
| 进阶阶段 | 异常处理 | try / except / finally | 错误处理机制 | 类似 try/catch |
| 进阶阶段 | 模块系统 | import / from import | 模块导入 | 类似 ES module |
| 进阶阶段 | 包结构 | Python 包结构 | `__init__.py` | 类似 npm package |
| 进阶阶段 | 标准库 | os、sys、pathlib | 系统相关操作 | 类似 Node 标准库 |
| 进阶阶段 | JSON处理 | json模块 | dumps / loads | 类似 JSON.parse |
| 进阶阶段 | 时间处理 | datetime模块 | 时间计算 | 类似 dayjs |
| 进阶阶段 | 迭代器 | iterator 协议 | iter / next | JS iterator |
| 进阶阶段 | 生成器 | generator | yield | JS generator |
| 进阶阶段 | 装饰器 | decorator | 函数包装 | 类似 AOP |
| 面向对象 | 类与对象 | class、实例化 | 属性、方法 | 类似 JS class |
| 面向对象 | 构造函数 | `__init__` | 初始化对象 | 类似 constructor |
| 面向对象 | 继承 | 类继承 | 父类 / 子类 | 类似 extends |
| 面向对象 | 多态 | 方法重写 | override | 面向对象特性 |
| 面向对象 | 魔术方法 | `__str__` `__repr__` `__add__` | 运算符重载 | JS 没有直接等价 |
| 面向对象 | 数据类 | dataclass | 简化数据结构 | 类似 TS interface + class |
| 工程化 | 包管理 | pip | 安装第三方库 | 类似 npm |
| 工程化 | 虚拟环境 | venv | 隔离依赖 | 类似 node_modules |
| 工程化 | 依赖管理 | requirements.txt | 锁定依赖 | 类似 package.json |
| 工程化 | 项目结构 | Python项目结构 | src结构 | 类似大型前端项目 |
| 工程化 | CLI工具 | argparse | 命令行参数 | 类似 Node CLI |
| 工程化 | 日志系统 | logging模块 | 日志级别 | 类似 winston |
| 工程化 | 测试 | pytest | 单元测试 | 类似 jest |
| 工程化 | 打包发布 | setuptools / poetry | 包发布 | 类似 npm publish |
| 工程化 | 文档生成 | sphinx | API文档 | 类似 typedoc |
| 工程化 | 代码规范 | black / flake8 | 代码格式化 | 类似 prettier |
| 高级 | 并发编程 | threading | 多线程 | 类似 WebWorker |
| 高级 | 进程编程 | multiprocessing | 多进程 | CPU并行 |
| 高级 | 异步编程 | asyncio | async/await | 类似 JS async |
| 高级 | 网络编程 | socket | 网络通信 | 类似 Node net |
| 高级 | Web框架 | Flask / FastAPI | Web API | 类似 Express |
| 高级 | ORM | SQLAlchemy | 数据库操作 | 类似 Prisma |
| 高级 | 爬虫技术 | requests / BeautifulSoup | 数据抓取 | 自动化 |
| 高级 | 自动化 | Selenium / Playwright | 浏览器自动化 | 前端自动测试 |
| 高级 | 数据处理 | numpy / pandas | 数据计算 | 类似 JS math libs |
| 高级 | Python解释器 | CPython架构 | 解释器实现 | Python运行机制 |
| 高级 | 编译流程 | AST → Bytecode | `.pyc` 文件 | Python编译过程 |
| 高级 | Python虚拟机 | Python VM | 字节码执行 | 类似 JVM |
| 高级 | 内存管理 | 引用计数 / GC | 垃圾回收 | 类似 JS GC |
| 高级 | GIL机制 | Global Interpreter Lock | 线程限制 | Python并发核心问题 |
| 高级 | C扩展 | C API / Cython | 扩展Python性能 | 类似 Node native addon |
| 高级 | Python源码 | CPython源码结构 | Objects / Python / Modules | 深入解释器 |

2. 笔记文件命名格式以`${模块索引}.${模块名}.md`

3. 笔记输出路径为`/back-end/python` 目录下
